# Little Interruptions

A tiny, free, open-source tray app inspired by the meditation bell: while you work, it rings a soft bell every so often and shows one short, gentle (sometimes funny) message. Then it gets out of the way.

- Free, no accounts, everything stays on your computer.
- Interval: 60 / 90 / 120 minutes, or any number of minutes you choose.
- No schedule to configure: the bell counts from when you sit down. Step away or sleep the machine and the next session starts fresh.
- Left-click the bell in the menu bar for a quick panel (time left, ring now, quiet for a while, change the interval). Right-click for the classic menu.
- Smart pause (macOS): if a call, video or presentation is keeping the display awake, or a microphone is in use, when a bell is due, the bell waits and rings once you're done.
- Messages live in local JSON packs (`/packs`). Once a day the app fetches the pack files from this repository and adds any new messages. It never deletes your local ones. This is the app's only network request (a plain GET of static JSON); you can turn it off in Settings.

> Status: early. macOS first, Windows next.

## Develop

Requirements: Node ≥ 22.18, pnpm, Rust (stable), and the [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/) for your OS.

```sh
pnpm install            # commit the generated pnpm-lock.yaml
pnpm test               # core logic tests (Vitest)
pnpm typecheck
pnpm validate:packs     # validates every file in /packs
pnpm dev                # runs the desktop app
pnpm build              # produces an installer
```

Before the daily update works, set your repository in `apps/desktop/src/config.ts` (`PACK_BASE_URL`, replace `OWNER/REPO`).

### Layout

- `packages/core` – pure TypeScript business logic (scheduling, message picking, pack validation/merging, tick handling). Deterministic and fully unit-tested.
- `apps/desktop` – Tauri v2 + React shell: tray, popup, settings window, native sound, idle detection.
- `packs` – message packs. See [packs/README.md](packs/README.md).
- `docs/superpowers/specs` – design notes.

### Icons

Placeholder icons are generated by `scripts/generate-assets.py`. To use your own: replace `apps/desktop/app-icon.png` and run `pnpm --filter desktop tauri icon app-icon.png`.

## Known gaps

- Unsigned macOS builds: on first launch, right-click the app → Open (Gatekeeper). Signing/notarization is not set up.
- No "launch at login" yet.
- Smart pause sees apps that keep the display awake (calls, video, presentations) and microphones in use. The microphone check can also trigger for a headset that is only playing sound; it has its own switch in Settings. It does not detect screen recording, and an app that always keeps the display awake (a "keep awake" utility) makes the user look permanently busy; switch it off in Settings in that case.
- Does not respect Do Not Disturb / Focus.
- Idle detection exists on macOS and Windows only.

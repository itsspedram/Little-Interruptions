# Handoff: Little Interruptions

Read this first, then `README.md`. Goal: continue the work on a fresh branch cut from `main`.

## What it is
Free, open-source, local-only menu-bar app that shows a gentle "drop" (sound + one kind or silly sentence) at intervals. Tauri v2 + React 19 + Tailwind 4, pnpm monorepo. Pure-TS logic lives in `packages/core`. macOS first, Windows later. Landing page: `site/index.html` (GitHub Pages, deployed by `.github/workflows/pages.yml`).

## Decisions (final)
- The concept is a **drop**, not a bell. Some internal names still say "bell" (`BellIcon`, the `bell` event, `bell-swing` keyframes); they are intentionally unchanged.
- `launchAtLogin` defaults to true. The login item is only synced after onboarding; nothing rings before onboarding.
- Welcome-back messages are a separate pool (`WELCOME_CATEGORY = "welcome_back"`). Regular categories: `gentle_caring`, `playful_weird`, `tiny_mindfulness`; `enabledCategories` is never empty.
- Display styles: `card`, `overlay` (one window per monitor), `notification`.
- Busy = display-sleep assertion OR (`smartPauseMic` AND mic in use).
- Sound: `soundChoice` is `random` or one of `SOUND_IDS` (drip, bloop, plink, pond, twin, glass, cave, tiny, leaf, bubble); default `drip`.
- Local only: no accounts, no telemetry. Pack messages are max 100 chars. Pack license: CC0 suggested, not yet added.

## Known problems
- `apps/desktop/src-tauri/assets/drops/*.wav` are **synthetic placeholders** generated by `scripts/generate-drops.py`. The owner finds them "mock" and wants **real CC0 drop recordings**. Replace the files, keep the names (or update `SOUND_IDS`, `SOUND_LABELS` in `ui/describe.ts`, README), add `assets/drops/CREDITS.md`.
- Not yet run on a real Mac (the cloud environment cannot build Tauri): onboarding wizard, the three display styles, overlay on multiple monitors, mic smart pause in a real call, login item, tray icon, sound playback.
- `Cargo.lock` changes whenever a Tauri plugin is added; commit it.

## Verified vs not
- Verified: `packages/core` tests (run `pnpm test`), `pnpm validate:packs`.
- Not verified: everything under `apps/desktop` that touches Tauri, CoreAudio (`mic.rs`), overlay windows, autostart.

## Working rules
- Branch every task from `main`. **Do not stack PRs**: earlier stacked PRs merged into each other's branches and never reached `main`.
- Core logic gets tests first (`packages/core`). UI/Rust changes: say plainly what you could not run.
- Follow existing patterns, Tailwind over extra CSS, no unnecessary dependencies.
- Commands: `pnpm dev`, `pnpm build`, `pnpm test`, `pnpm typecheck`, `pnpm validate:packs`.
- Node >= 22.18.
